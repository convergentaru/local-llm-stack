# Два монитора в Ubuntu + i3: ARandR, сохранение профиля и автозапуск

Пошаговая инструкция для начинающих. Здесь описан проверенный рабочий сценарий: расположить два монитора так, чтобы мышь переходила между ними в правильном направлении, сохранить профиль ARandR и автоматически применять его при запуске i3.

> **Важно:** имена выходов, разрешения и координаты ниже относятся к одной конкретной машине. На другом компьютере они могут отличаться. Сначала смотрите фактический вывод `xrandr --query`, а затем адаптируйте команды.

## Что в итоге получится

- Большой монитор `HDMI-0`: слева, 1920×1080, координаты `0x0`, основной.
- Маленький монитор `DP-0`: справа и немного ниже, 1024×768, координаты `1920x216`.
- Профиль ARandR: `~/.screenlayout/monitors.sh`.
- i3 запускает этот профиль при старте графической сессии.

Схема координат: начало экрана — левый верхний угол. У большого монитора левая верхняя точка `0,0`. Второй монитор начинается на 1920 пикселей правее и на 216 пикселей ниже.

## 1. Проверить, какие мониторы видит система

Откройте терминал и выполните:

```bash
xrandr --query
```

Команда только читает текущее состояние. Найдите строки с `connected`: это подключённые выходы. В нашем случае они назывались `HDMI-0` и `DP-0`.

Для короткого вывода:

```bash
xrandr --query | grep -E ' connected|Screen 0'
```

Пример результата после настройки:

```text
Screen 0: minimum 8 x 8, current 2944 x 1080, maximum 32767 x 32767
HDMI-0 connected primary 1920x1080+0+0 ...
DP-0 connected 1024x768+1920+216 ...
```

Что означают координаты:

- `1920x1080+0+0` — разрешение 1920×1080, начало в точке 0,0.
- `1024x768+1920+216` — разрешение 1024×768, начало на 1920 пикселей вправо и 216 вниз.
- `primary` — основной монитор, на котором многие приложения открывают панели и диалоги.

## 2. Расставить мониторы в ARandR

1. Запустите ARandR из меню приложений или командой `arandr`.
2. В окне программы будут прямоугольники подключённых экранов.
3. Перетащите их так, как мониторы стоят на столе. Если маленький экран физически справа, поставьте его справа и при необходимости немного ниже.
4. При необходимости выберите подходящее разрешение в меню соответствующего экрана.
5. Примените раскладку кнопкой с галочкой (Apply).

**Apply применяет схему немедленно, но сам по себе не гарантирует сохранение её для следующего входа в систему.**

После применения проверьте координаты:

```bash
xrandr --query | grep -E ' connected|Screen 0'
```

Переместите мышь к краю одного экрана. Если переход идёт не в ту сторону, вернитесь в ARandR, поправьте расположение прямоугольников и снова нажмите Apply.

## 3. Сохранить профиль в файл

В ARandR выберите **Layout → Save As…** (название пункта может немного отличаться) и сохраните профиль по этому пути:

```text
/home/ВАШ_ПОЛЬЗОВАТЕЛЬ/.screenlayout/monitors.sh
```

Подставьте имя своей учётной записи, если указываете абсолютный путь. Обычно удобнее использовать сокращённую запись `~`, которая означает домашний каталог текущего пользователя:

```text
~/.screenlayout/monitors.sh
```

Если каталог `.screenlayout` ещё не существует, создайте его:

```bash
mkdir -p ~/.screenlayout
```

Не путайте **Apply** и **Save As**: первое применяет схему сейчас, второе записывает сценарий, который сможет повторить эту схему позже.

## 4. Проверить сохранённый файл

Убедитесь, что файл появился:

```bash
ls -l ~/.screenlayout/monitors.sh
```

Прочитайте содержимое, ничего не запуская:

```bash
cat ~/.screenlayout/monitors.sh
```

В нашем профиле получилось:

```sh
#!/bin/sh
xrandr --output HDMI-0 --primary --mode 1920x1080 --pos 0x0 --rotate normal --output DP-0 --mode 1024x768 --pos 1920x216 --rotate normal --output DP-1 --off --output DP-2 --off --output DP-3 --off --output DP-4 --off --output DP-5 --off
```

Скрипт задаёт разрешение, положение и ориентацию двух мониторов. Он также отключает выходы `DP-1`–`DP-5`, если они присутствуют в системе. **Не копируйте этот список выходов вслепую на другой компьютер**: сначала проверьте имена выходов через `xrandr --query`.

## 5. Убедиться, что скрипт исполняемый

Проверьте права:

```bash
ls -l ~/.screenlayout/monitors.sh
```

В нашем случае начало строки было:

```text
-rwx------ 1 ИМЯ_ПОЛЬЗОВАТЕЛЯ ИМЯ_ГРУППЫ ... /home/ИМЯ_ПОЛЬЗОВАТЕЛЯ/.screenlayout/monitors.sh
```

Расшифровка:

- `r` — можно читать;
- `w` — можно изменять;
- `x` — можно запускать как программу;
- три группы прав относятся к владельцу, группе и остальным пользователям.

Буквы `rwx` сразу после первого дефиса означают, что владелец может читать, изменять и запускать файл. Поэтому в нашем случае дополнительный `chmod` не понадобился.

Если у файла нет права запуска, исправьте его:

```bash
chmod u+x ~/.screenlayout/monitors.sh
```

Эта команда меняет права только у указанного файла. После этого можно применить профиль вручную:

```bash
~/.screenlayout/monitors.sh
```

Это уже **не проверка, а действие**: команда изменит текущую раскладку экранов. Если вы только что нажали Apply в ARandR и всё работает, повторно запускать скрипт необязательно.

## 6. Сделать резервную копию конфигурации i3

Прежде чем редактировать конфигурацию, сохраните копию:

```bash
cp -a ~/.config/i3/config ~/.config/i3/config.bak-before-monitors
```

Команда создаёт резервную копию исходного файла. Она не заменяет и не удаляет оригинал.

## 7. Добавить профиль в автозапуск i3

Откройте конфигурацию:

```bash
nano ~/.config/i3/config
```

Добавьте в конец файла отдельной строкой:

```text
exec --no-startup-id ~/.screenlayout/monitors.sh
```

Сохраните файл в nano: **Ctrl+O**, затем **Enter**, после этого выйдите через **Ctrl+X**.

Что означает строка:

- `exec` — запустить команду при запуске i3;
- `--no-startup-id` — не создавать startup notification для этой команды;
- `~/.screenlayout/monitors.sh` — путь к нашему скрипту.

Команда `exec` выполняется при запуске i3. Обычная перезагрузка конфигурации сочетанием `Super+Shift+C` не запускает её повторно. Для немедленного применения профиля можно вручную выполнить `~/.screenlayout/monitors.sh`. При следующем запуске i3 профиль будет применён автоматически.

> Альтернатива: `exec_always --no-startup-id ~/.screenlayout/monitors.sh` запускает скрипт также при перезагрузке конфигурации. Обычно для простого профиля мониторов достаточно `exec`; не добавляйте обе строки одновременно.

## 8. Проверить конфигурацию i3 перед применением

Выполните:

```bash
i3 -C -c ~/.config/i3/config
```

Это проверка конфигурации: она не перезапускает i3. При отсутствии ошибок команда может завершиться без вывода. Чтобы проверить код завершения, сразу после неё выполните:

```bash
echo $?
```

Код `0` означает, что предыдущая команда завершилась успешно. Ненулевой код обычно указывает на ошибку; внимательно прочитайте сообщение и исправьте её до перезагрузки конфигурации.

Затем перечитайте конфигурацию i3 сочетанием **Super+Shift+C**. Перезагружать компьютер не требуется. Раскладка мониторов, уже применённая ARandR, должна остаться в текущем сеансе; автоматическое применение из `exec` произойдёт при следующем запуске i3.

## 9. Проверить результат после следующего входа

После выхода и нового входа в графическую сессию выполните:

```bash
xrandr --query | grep -E ' connected|Screen 0'
```

Сравните расположение с сохранённым профилем и проверьте мышью переход между экранами.

Если схема не восстановилась, проверьте по порядку:

```bash
ls -l ~/.screenlayout/monitors.sh
cat ~/.screenlayout/monitors.sh
grep -n 'screenlayout/monitors.sh' ~/.config/i3/config
i3 -C -c ~/.config/i3/config
```

Если требуется проверить сам сценарий вручную, запускайте его из терминала:

```bash
~/.screenlayout/monitors.sh
```

Если появится сообщение об ошибке, сохраните его полностью. Частая причина — выходы мониторов называются иначе, чем в файле профиля.

## 10. Как отменить изменение

Если после редактирования i3 возникла проблема, восстановите резервную копию:

```bash
cp -a ~/.config/i3/config.bak-before-monitors ~/.config/i3/config
```

Затем проверьте файл:

```bash
i3 -C -c ~/.config/i3/config
```

После успешной проверки перечитайте конфигурацию через **Super+Shift+C**.

Восстановление конфигурации i3 не удаляет сохранённый профиль `~/.screenlayout/monitors.sh`. Если понадобится, его можно будет запускать вручную или снова подключить к автозапуску.

## Краткая памятка

| Задача | Команда / действие |
|---|---|
| Посмотреть выходы и координаты | `xrandr --query` |
| Настроить расположение визуально | ARandR → перетащить экраны → Apply |
| Сохранить профиль | ARandR → Layout → Save As… |
| Проверить профиль | `cat ~/.screenlayout/monitors.sh` |
| Проверить права запуска | `ls -l ~/.screenlayout/monitors.sh` |
| Запустить профиль сейчас | `~/.screenlayout/monitors.sh` |
| Проверить i3 | `i3 -C -c ~/.config/i3/config` |
| Перечитать конфигурацию i3 | `Super+Shift+C` |
| Сделать резервную копию i3 | `cp -a ~/.config/i3/config ~/.config/i3/config.bak-before-monitors` |

## Что нужно помнить

1. Сначала настройте и проверьте схему в ARandR.
2. Затем сохраните её в файл.
3. Проверьте содержимое и право запуска.
4. Только после резервной копии добавляйте строку в автозапуск i3.
5. Проверьте конфигурацию до её перечитывания.
6. Не копируйте разрешения и имена выходов на другой компьютер без проверки.

Эта процедура сохраняет **расположение мониторов**, а не сами физические настройки монитора вроде яркости или цветового профиля. Она также не меняет настройки клавиатурной раскладки.
