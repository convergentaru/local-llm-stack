# Roadmap — JARVIS Holographic Interface

Цель — сначала получить работающий локальный жестовый интерфейс, затем собрать оптический прототип, а после испытаний добавить безопасный адаптер к Hermes.

## Этап 0 — выбрать первый физический формат

- [ ] Начать с бюджетного Pepper's Ghost, а не с покупки light-field display.
- [ ] Решить, используем ли телефон как экран или отдельный монитор.
- [ ] Замерить размер изображения и место на столе.
- [ ] Выбрать акриловую пирамиду/наклонную пластину и безопасную конструкцию корпуса.
- [ ] Зафиксировать, что цель — оптическая иллюзия, не свободно висящее изображение.

**Готово, когда:** есть размеры конструкции, вариант экрана и список материалов; дорогие компоненты пока не покупаем.

## Этап 1 — 3D UI без камеры и акрила

- [ ] Создать Three.js сцену с JARVIS-ядром и вращаемым объектом.
- [ ] Добавить dev-панель: landmarks, gesture, confidence, FPS и latency.
- [ ] Сделать симулятор жестов с клавиатуры/мыши.
- [ ] Вынести 3D-модель/аватар в систему загрузки объектов.

**Готово, когда:** сцену можно управлять мышью и тестовыми событиями без аппаратуры.

## Этап 2 — реальное распознавание рук

- [ ] Проверить MediaPipe Hand Landmarker на текущей Ubuntu, Python и веб-камере.
- [ ] Зафиксировать версии Python и зависимостей; проверить модельный task-файл.
- [ ] Получить поток landmarks для одной и двух рук.
- [ ] Реализовать pinch, point, open palm и fist с порогами и временной фильтрацией.
- [ ] Показывать состояние трекера и причины отказа от жеста.

**Готово, когда:** жесты достаточно устойчивы в обычном окне браузера и не вызывают много ложных срабатываний.

## Этап 3 — локальный протокол событий

- [ ] Создать WebSocket endpoint, привязанный к localhost по умолчанию.
- [ ] Использовать типизированные сообщения: gesture, confidence, timestamp, sequence.
- [ ] Отбрасывать старые, повторные и низкоуверенные события.
- [ ] Не передавать кадры камеры — только малые события/координатные дельты.
- [ ] Добавить stop switch и лог частоты ошибок.

**Готово, когда:** отключение сети/камеры не приводит к повтору последнего действия или случайному изменению объекта.

## Этап 4 — four-view renderer

- [ ] Сделать четыре синхронных вида для четырёх граней пирамиды.
- [ ] Добавить калибровку масштаба, положения и угла отражателя.
- [ ] Переключать обычный режим разработки и режим вывода на пирамиду.
- [ ] Настроить яркость, чёрный фон, контраст и тестовый шаблон.
- [ ] Собрать первый корпус и проверить изображение при затемнённом окружении.

**Готово, когда:** 3D-объект визуально появляется внутри конструкции и виден с предусмотренных сторон.

## Этап 5 — совместная работа жестов и оптики

- [ ] Замерить задержку camera → gesture → 3D renderer.
- [ ] Проверить ложные действия, потерю руки и возвращение в кадр.
- [ ] Проверить устойчивость при разных расстояниях и освещении.
- [ ] Отдельно измерить читаемость/яркость изображения в конструкции.
- [ ] Не интегрировать Hermes до прохождения этих тестов.

**Готово, когда:** есть демонстрационное видео, test notes и воспроизводимый способ сборки.

## Этап 6 — JARVIS HUD

- [ ] Добавить состояние Hermes только в режиме read-only.
- [ ] Показать задачу, активность, статус модели и ошибки.
- [ ] Добавить голосовую обратную связь отдельно от жестовой системы.
- [ ] Включить жесты только для навигации по заранее разрешённым элементам.
- [ ] Требовать явное подтверждение для чувствительных действий.

## Этап 7 — специализированный дисплей (необязательно)

- [ ] Сравнить DIY Pepper's Ghost с Looking Glass / light-field устройством.
- [ ] Проверить совместимость с Linux и API до покупки.
- [ ] Рассчитать полную стоимость и необходимое пространство.
- [ ] Мигрировать renderer только если специализированный дисплей даёт ощутимую пользу.

## Приоритет следующей сессии

1. [ ] Создать Three.js страницу с демонстрационным объектом.
2. [ ] Подключить симулятор жестов и отладочную панель.
3. [ ] Проверить MediaPipe на Ubuntu и веб-камере.
4. [ ] После стабилизации ПО перейти к размерам акриловой конструкции.

## Пока не делать

- Не покупать дорогой spatial display.
- Не обещать настоящую голограмму: первая версия использует Pepper's Ghost.
- Не запускать команды Hermes или shell только по распознанному жесту.
- Не предполагать, что готовый upstream demo, предназначенный для Windows, без изменений работает на Ubuntu.
