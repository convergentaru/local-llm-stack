# JARVIS Holographic Interface

> Исследовательский проект: настольный визуальный интерфейс JARVIS с эффектом «парящей» 3D-модели и управлением жестами рук. Цель — недорогой самодельный прототип, который можно развивать на Ubuntu и позднее связать с Hermes.

## Идея

Сделать физическое устройство в духе JARVIS / Iron Man: на столе находится прозрачная конструкция, внутри которой кажется, что висит 3D-объект или аватар. Пользователь может жестами поворачивать, перемещать, выбирать или масштабировать объект. В дальнейшем интерфейс сможет отображать состояние Hermes, активную задачу и голосовой диалог.

Важно различать технологии:

- **Pepper's Ghost** — оптическая иллюзия отражения изображения от прозрачной поверхности. Самый дешёвый DIY-путь: экран/телефон + прозрачная акриловая пирамида или наклонная пластина + тёмный корпус. Объект кажется парящим внутри конструкции, но это не свободно висящая в воздухе физическая голограмма.
- **Light-field / spatial display** — специализированный дисплей выдаёт несколько видов изображения для объёмного впечатления без очков. Это аккуратнее, но заметно дороже.
- **Изображение, реально сформированное в воздухе без носителя** — не рассматривается для первого прототипа: это существенно более сложная технология.

## Базовый прототип

1. Использовать экран ноутбука, монитор или смартфон для вывода четырёх синхронизированных видов 3D-модели.
2. Сделать небольшую акриловую пирамиду/наклонную пластину и чёрный корпус, уменьшающий паразитные отражения.
3. Веб-камера наблюдает за руками.
4. MediaPipe Hand Landmarker распознаёт landmarks кисти; логика жестов преобразует их в действия.
5. Three.js отображает и меняет 3D-сцену; WebSocket передаёт небольшие события между трекером и UI.
6. Сначала жесты меняют только визуальную сцену. Интеграцию с Hermes разрешаем после проверки устойчивости и безопасного протокола.

## Архитектура

    USB webcam
       |
       v
    MediaPipe Hand Landmarker (Python)
       |
       v
    gesture engine: pinch / grab / point / open palm / fist
       |
       v
    local WebSocket bridge (typed allowlist events only)
       |
       v
    Three.js / Web UI
       |                         later: JARVIS application adapter
       v                                      |
    four-view renderer                         v
       |                                   Hermes Agent
       v
    phone / monitor + acrylic reflector

На первом этапе EEG/BCI не нужен: жесты, голос и EEG — отдельные способы ввода, их следует проверять независимо.

## Жесты первого прототипа

Начальный набор — только визуальные действия:

- **Pinch + drag:** захватить и переместить объект.
- **Point:** выбрать объект или элемент UI.
- **Open palm held:** возобновить сцену после паузы.
- **Fist held:** поставить сцену на паузу.
- **Two-hand distance:** изменить масштаб.
- **Cancel gesture:** отменить выделение или закрыть локальную панель.

Жесты должны обрабатываться с порогом уверенности, временной стабилизацией и cooldown. Камера может потерять руку или сработать на случайное движение, поэтому жест не должен непосредственно запускать опасное действие Hermes.

## Принципы

1. **Сначала дешёвый физический эффект.** Используем экран и прозрачный материал; специальный spatial display оставляем необязательным будущим апгрейдом.
2. **Local-first.** Камера и обработка жестов работают локально; видеопоток не отправляется в облако.
3. **Разделение слоёв.** Захват камеры, landmarks, логика жестов, отрисовка и управление Hermes — независимые модули.
4. **Безопасность.** Визуальные жесты не являются произвольными shell-командами. Чувствительные действия требуют отдельного подтверждения.
5. **Сначала монитор, потом оптический корпус.** Разработать и откалибровать жесты в обычном окне браузера, затем переключить renderer на four-view layout для Pepper's Ghost.
6. **Проверять Ubuntu-совместимость.** Некоторые готовые демонстрации ориентированы на Windows; не считать upstream-проект готовым к запуску на Ubuntu без проверки зависимостей.

## Референсы и исходники

- [ojasra0kulkarni/hologram-system](https://github.com/ojasra0kulkarni/hologram-system) — близкий по замыслу open-source-проект: webcam → MediaPipe → gesture engine → WebSocket → phone/four-view renderer. README приводит измерения и setup-инструкции, помеченные как Windows; для Ubuntu потребуется адаптация.
- [Google MediaPipe Hand Landmarker for Python](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python) — официальный API для landmarks кисти.
- [Pony Stark / StarkHacks 2026](https://github.com/dylankainth/starkhacks) — DIY Pepper's Ghost пример: iPhone использует ARKit/Vision для рук и передаёт события на ноутбук.
- [Looking Glass Go](https://checkout.lookingglassfactory.com/products/looking-glass-go) — компактный light-field display, если позднее решим перейти от отражателя к специализированному пространственному дисплею.
- [Looking Glass WebXR](https://github.com/Looking-Glass/looking-glass-webxr) — интеграция пространственного дисплея с WebXR и Three.js.
- [Ultraleap Hand Tracking](https://docs.ultraleap.com/hand-tracking/index.html) — альтернатива обычной веб-камере с IR-камерами; системные требования каждой версии SDK проверять отдельно.

## Ограничения и риски

- Pepper's Ghost требует правильной геометрии, яркого изображения с тёмным фоном, контролируемого внешнего освещения и оптической калибровки.
- Четырёхсторонняя пирамида расходует площадь экрана на несколько видов; яркость ниже, чем у прямого монитора.
- Обычная RGB-веб-камера зависит от освещения, расстояния и перекрытий.
- Сначала не подключаем жесты к управлению окнами, файлами, терминалом или инструментами Hermes. Начальный объект управления — только 3D-модель и безопасные демонстрационные элементы UI.
- Не называем Pepper's Ghost настоящей голограммой, чтобы не завышать ожидания.

## Критерий готовности первой версии

- Локальная 3D-сцена реагирует на pinch / point / fist / open palm.
- Dev-панель показывает состояние трекера, жест, уверенность, FPS и задержку.
- Отслеживание можно выключить одним действием.
- Видео камеры остаётся локальным.
- Four-view renderer даёт приемлемую видимость в собранной акриловой конструкции.
- Потеря камеры приводит к no-op, а не к случайному действию.
- Hermes-адаптер остаётся выключенным до отдельного тестирования.

## Статус

**Research / planned.** Документ описывает направление, а не подтверждает, что оборудование собрано или код проверен на машине пользователя. Начать с веб-камеры, браузерного 3D UI и симулятора жестов; не покупать специальный дисплей до этого этапа.
