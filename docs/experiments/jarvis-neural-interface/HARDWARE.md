# Hardware & safety notes — JARVIS Neural Interface

## Вывод на данный момент

Не начинать с пайки. Первый программный этап должен работать с симулированными событиями. Для первого подключения реального сигнала следует сравнить готовое устройство с открытым DIY-проектом, учитывая поддержку Ubuntu, расходы на электроды и безопасную изоляцию.

## Вариант A — начать без EEG-гарнитуры

Использовать симулятор событий UI. BrainFlow поддерживает Synthetic Board и Playback File Board, что позволяет предварительно тестировать часть потоковой обработки без реального устройства; см. [BrainFlow Supported Boards](https://github.com/brainflow-dev/brainflow/blob/master/docs/SupportedBoards.rst).

**Плюсы:** отсутствует стоимость оборудования; можно сразу создать UI, протокол событий и проверки безопасности.

**Минусы:** не подтверждает качество EEG-захвата или классификации на живом сигнале.

**Рекомендация:** первый шаг.

## Вариант B — готовая гарнитура

BrainFlow перечисляет несколько поддерживаемых семейств EEG-устройств, в том числе Muse и OpenBCI: [BrainFlow supported boards](https://brainflow.org/get_started/).

Перед выбором конкретной модели проверить:

- работает ли Bluetooth/USB-подключение с текущей Ubuntu;
- есть ли доступ к сырому EEG или достаточному потоку данных;
- требуется ли сборка BrainFlow из исходников;
- какие электроды и расходники входят в комплект;
- есть ли публичные инструкции для Linux;
- допускает ли лицензия SDK нужный сценарий использования.

Для Muse 2 документация BrainFlow указывает необходимость на Linux установить libdbus и, вероятно, собрать BrainFlow с BLE-поддержкой из исходного кода. Поэтому это не следует считать plug-and-play до проверки на данном компьютере: [SupportedBoards.rst — Muse 2](https://github.com/brainflow-dev/brainflow/blob/master/docs/SupportedBoards.rst).

Не полагаться только на маркетинговые функции готовой гарнитуры: проверить доступность потоковых данных для собственного приложения.

## Вариант C — DIY Low-Cost-EEG

Источник: [XavierAsghar/Low-Cost-EEG](https://github.com/XavierAsghar/Low-Cost-EEG).

По описанию автора:

- ESP32-S3;
- аналоговый фронтенд TI ADS1299;
- до 8 входных каналов для электродов;
- передача по Bluetooth Low Energy на host-компьютер;
- поток в Lab Streaming Layer;
- firmware, Python host-код и аппаратные производственные файлы доступны в репозитории;
- заявленные автором затраты на компоненты — £69.07 для 4 каналов и £99.92 для 8 каналов (это цифры из upstream README, а не гарантированная текущая цена; отдельно могут потребоваться электроды, изготовление PCB, корпус, доставка и тестирование).

Лицензия upstream-проекта — GPL-3.0. Проверить лицензию ещё раз перед производным распространением.

### Ограничения DIY

- Это экспериментальное измерительное устройство, а не медицинский/сертифицированный BCI-продукт.
- Автор предупреждает: при подключённых к человеку электродах устройство должно питаться от аккумулятора, а USB-C должен быть отключён для обеспечения электрической изоляции от сети.
- Не подключать USB, зарядное устройство или другие сетевые/заземлённые средства вопреки руководству проекта.
- Прежде чем подключать электроды к человеку, изучить все документы проекта, проверить сборку и провести оценку электрической безопасности. Если безопасность не ясна — не проводить испытание на человеке.

## Сигнальные парадигмы — не оборудование

Разные типы сигналов требуют разных задач и подготовки:

- SSVEP: зрительный отклик на визуальные стимулы. Может подходить для выбора нескольких пунктов, но мерцание может вызывать дискомфорт.
- P300: отклик на целевой стимул в последовательности событий. Как правило, требуется повторение и настройка классификатора.
- Motor imagery: классификация сигналов, связанных с мысленным представлением движения; оставить на более поздний этап, поскольку надёжное индивидуальное распознавание нельзя гарантировать.

Никакая из этих схем не равна универсальному чтению мыслей или свободной диктовке текста.

## Локальное программное обеспечение

- [BrainFlow](https://brainflow.org/) — API для получения и обработки данных с поддерживаемых устройств, включая synthetic/playback варианты.
- [Lab Streaming Layer](https://github.com/sccn/labstreaminglayer) — потоковая передача многоканальных временных данных.
- [XavierAsghar/Low-Cost-EEG](https://github.com/XavierAsghar/Low-Cost-EEG) — возможный путь для собственного аппаратного прототипа.

## Проверки до покупки

- [ ] Выбран конкретный тип сигнала и сценарий использования.
- [ ] Проверена поддержка Ubuntu и способ захвата сырого сигнала.
- [ ] Известны цена, расходные материалы и требования к изготовлению.
- [ ] Прочитаны upstream safety warning, user guide и hardware report.
- [ ] Определены способы электрической изоляции.
- [ ] В программе реализованы NO-OP при потере сигнала и отдельное подтверждение опасных действий.
