# Roadmap — LEGO Manipulation Robot

## Этап 0 — выбрать минимальную задачу

- [ ] Решить, что первый результат — сортировка цветных деталей, pick-and-place или захват конкретных part ID.
- [ ] Собрать набор 10–20 одинаковых тестовых деталей и 3–4 цвета.
- [ ] Описать измерения/критерии успеха.
- [ ] Проверить уже имеющиеся LEGO motors/sensors/hubs и не покупать kit до инвентаризации.

**Готово, когда:** тестовые детали, задача и критерии зафиксированы.

## Этап 1 — базовый сортировщик

- [ ] Изучить официальный LEGO Education EV3 Color Sorter и оценить, подходят ли имеющиеся детали/набор.
- [ ] Решить: LEGO sensor + LEGO motors для простого закрытого сортировщика или USB camera + color/vision model.
- [ ] Создать таблицу confusion matrix для цветов и протестировать освещение.
- [ ] Реализовать три лотка и загрузку по одной детали.
- [ ] Записывать correct / incorrect / unknown; неизвестный цвет не должен автоматически классифицироваться.

**Готово, когда:** измерена accuracy на заданном наборе и система безопасно обрабатывает Unknown.

## Этап 2 — предметная локализация

- [ ] Использовать фиксированную overhead camera и матовую рабочую поверхность.
- [ ] Калибровать pixel-to-workspace mapping.
- [ ] Определять цвет, bounding box/маску и ориентацию на ограниченном наборе деталей.
- [ ] Позже сопоставить наблюдение с part IDs / LDraw reference models.
- [ ] При неоднозначности запросить пользовательское подтверждение.

**Готово, когда:** система стабильно локализует выбранные детали в известной рабочей зоне.

## Этап 3 — базовый манипулятор и gripper

- [ ] Сравнить SO-ARM101, LEGO EV3/SPIKE-style educational robot and one simple single-purpose gripper.
- [ ] Проверить BOM, CAD license, моторы, контроллер, питание и доступность деталей.
- [ ] Напечатать/собрать руку и установить аппаратный emergency stop.
- [ ] Откалибровать joints и рабочую область.
- [ ] Начать с teleoperation/manual control, затем repeatable motions.
- [ ] Использовать простые parallel gripper; не брать multi-finger hand как первый hardware purchase.

**Готово, когда:** оператор может безопасно перемещать руку, а controller отслеживает limits и stop.

## Этап 4 — надёжный pick-and-place

- [ ] Сделать известную позицию подачи деталей и места размещения.
- [ ] Добавить wrist/overhead camera (по доступности) и процедуру повторной локализации.
- [ ] Реализовать pick, lift, move, place, verify, retry/stop.
- [ ] Измерять pick success, drop rate, cycle time и errors.
- [ ] Отдельно тестировать один тип детали; не расширять каталог пока точность не измерена.

**Готово, когда:** успешность подтверждена серией испытаний и описаны условия, где система не работает.

## Этап 5 — интеграция с BOM и LDraw

- [ ] Прочитать BOM без изменений и построить part inventory.
- [ ] Привязать source bins к known part IDs.
- [ ] Отобразить current assembly step и next required parts.
- [ ] Сделать structured robot API и dry-run mode.
- [ ] Hermes может предложить следующую задачу, но исполнитель валидирует каждое действие.
- [ ] Логировать результат и объяснимую причину остановки.

**Готово, когда:** robot task соответствует BOM и есть воспроизводимый сухой прогон без движения моторов.

## Этап 6 — контролируемая сборка подузла

- [ ] Выбрать простой детерминированный подузел с мало деталей.
- [ ] Создать fixture/jig для фиксации основы и ограничения свободы детали.
- [ ] Добавить ориентацию детали и сопоставление с assembly step.
- [ ] Ограничить контакт/усилие; испытать на расходных деталях.
- [ ] Проверять посадку камерой и/или отдельным датчиком.
- [ ] Отдельно измерять повреждения, повторные попытки и ошибки.

**Готово, когда:** система воспроизводимо собирает один небольшой узел, а не просто складывает детали рядом.

## Этап 7 — dexterous hand / multi-finger manipulation (long-term)

- [ ] После доказанного pick-and-place определить, какие операции не справляются simple gripper.
- [ ] Оценить LEAP Hand V1/V2 и их актуальные hardware/CAD license terms.
- [ ] Проверить управление, питание, калибровку, обратную связь и стоимость.
- [ ] Сформулировать отдельные benchmarks для поворота, re-grasp и соединения деталей.
- [ ] Не интегрировать с LLM без ограниченного controller и safety validation.

## Следующая сессия: практический старт

1. [ ] Инвентаризировать, есть ли LEGO EV3/SPIKE hub, color sensor, motors и что уже лежит в ldraw-nova.
2. [ ] Выбрать стартовый объект: 3 цвета одинаковых кирпичей (sorting) или 10 одинаковых кирпичей (pick-place).
3. [ ] Разделить перception, robot controller и Hermes task planner.
4. [ ] Сделать сначала software simulation / dry-run без моторов.

## Пока не делать

- Не покупать дорогую многопальцевую руку до первого доказанного сценария.
- Не считать color sensor полноценным распознаванием геометрии/part ID.
- Не считать простой gripper готовым для надёжного LEGO snap-fit assembly.
- Не давать Hermes свободный доступ к приводам.
