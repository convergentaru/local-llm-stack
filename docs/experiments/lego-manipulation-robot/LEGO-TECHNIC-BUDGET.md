# Budget — LEGO Technic prototype without 3D printing

## Recommendation

Сначала собрать механический макет из имеющихся LEGO Technic деталей. Это позволяет проверить механику без 3D-печати и без покупки сторонней роботизированной руки. Точная стоимость моторизованной версии зависит от того, какие Technic элементы, моторы, hub и аккумулятор уже есть.

| Комплектация | Расходы | Что проверяем |
|---|---|---|
| Ручной макет из уже имеющихся деталей | Без дополнительных закупок, если детали в наличии | Геометрия, кинематика, жёсткость, рабочая зона и клешня |
| Макет + имеющиеся совместимые моторы/hub | Возможно, только расходники/недостающие детали | Движение осей и простой захват |
| Нужны отдельные моторы или hub | Рассчитать по точной модели до покупки | Моторизация 2 осей, обратная связь и связь с Ubuntu |
| ROS 2/Python software | Само ПО open source | Время интеграции и тестирования; возможен USB/BLE адаптер |

Не покупаем набор, пока не составлен список имеющихся деталей и оборудования. Новые hub и моторы могут стоить дороже самой механической LEGO-конструкции. Особенно внимательно проверяем наличие прошивки и совместимость с Ubuntu.

## Минимальная конфигурация

- Technic liftarms, рамы, pins, axles, bushes и connectors;
- шестерни, если нужны передаточное отношение или более медленное движение;
- простая клешня;
- один совместимый hub и два мотора для первой моторизованной версии;
- совместимые аккумулятор и кабель;
- позже — камера над рабочей зоной.

На первом этапе не нужны: 3D-принтер, custom CAD parts, шестикоординатная рука, многопальцевая кисть, force/torque sensor и ROS 2 MoveIt. Сначала добиваемся безопасного повторяемого движения на малой скорости.

## Рекомендуемый порядок

1. Инвентаризировать Technic детали, hub, моторы и сенсоры.
2. Собрать вручную двухосевую руку с клешнёй.
3. Проверить механику и затем добавить два мотора.
4. Сделать самый простой host-side Python adapter.
5. Только после стабильного pick-and-place рассматривать ROS 2 и компьютерное зрение.

Для более дорогой альтернативы см. [SO-ARM101 budget](BUDGET.md); он описывает отдельную руку с 3D-печатными деталями и не обязателен для первого прототипа.
