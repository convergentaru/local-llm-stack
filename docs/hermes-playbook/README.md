## Текущее состояние на 2026-10-26

- Пользователь сообщил, что после серии изменений интерфейс показывает контекст примерно 98K и модель снова работает в обычном режиме.
- В предыдущем журнале также появлялись сообщения о росте контекста до 96K, а соединение с provider custom несколько раз завершалось ошибкой APIConnectionError и исчерпанием автоматических повторов.
- Ранее документировалась проблема, где интерфейс показывал 65 536 токенов, а запрос порядка 22 737 токенов отклонялся. Исторический отчёт описывал расхождение значений в конфигурации Hermes, параметрах запуска llama-server и endpoint /props. Все детали следует перепроверять по фактическим журналам и конфигурации.
- Постоянная память Hermes сообщала о превышении лимита: 2 303 символа при лимите 2 200. Попытка редактирования не завершилась успешно.
- Локальный коммит 6714112 был создан, но предыдущая отправка в GitHub не состоялась из-за отсутствия аутентификации.

Эти сведения являются исходным журналом наблюдений, а не доказательством единственной установленной первопричины.

## Как пользоваться

- Начинай с самой узкой инструкции, соответствующей текущему симптому.
- Не запускай одновременно несколько крупных задач через один CLI-сеанс.
- Сначала сохраняй рабочее состояние и собирай журналы; изменения выполняй только после установления причины.
- После успешного решения добавляй краткий подтверждённый факт в постоянную память Hermes, а подробное описание — в этот репозиторий.
- Не называй решение проверенным, пока не проведён соответствующий тест.
- Не помещай сюда секреты, токены, частные юридические документы и другие приватные данные.
